# 可手推的公式卡

只收面试里会被要求当场推导的式子。每条先写结论，再写四行以内的推导，最后给一个可以口算的检查。
公式全表在 [COURSE-QA](COURSE-QA.md)，数字例子在 [PORTFOLIO](PORTFOLIO.md)。

## 策略梯度：过去的奖励可以丢掉

`∇J = E[Σ_t ∇log π(a_t|s_t) · Σ_{t'≥t} r_{t'}]`。

轨迹概率 `P(τ) = ρ_0(s_0) Π_t P(s_{t+1}|s_t,a_t) π(a_t|s_t)`。
`log P` 对 θ 求导时，环境项不含 θ，只剩 `Σ_t ∇log π(a_t|s_t)`。
`t' < t` 的奖励与 `a_t` 独立，`E[∇log π(a_t|s_t) · r_{t'}] = r_{t'} ∇Σ_a π = 0`。
所以只留 reward-to-go。检查：把奖励整体加一个常数，梯度不变。

## baseline 无偏

`E_{a~π}[∇log π(a|s) · b(s)] = b(s) ∇_θ Σ_a π(a|s) = b(s) ∇1 = 0`。

b 只能依赖 s，不能依赖 a。依赖 a 的 baseline 有偏，除非再做重要性修正。

## GAE

`δ_t = r_t + γ(1−done_t) V(s_{t+1}) − V(s_t)`，`Â_t = δ_t + γλ(1−done_t) Â_{t+1}`。

`λ=0` 就是一步 TD。`λ=1` 把 V 全部消掉，回到 reward-to-go 减 V(s_t)。
检查：终止步 `done=1`，后面的项必须是 0，否则会把下一回合的价值加进来。

## DPO 的隐式奖励

Bradley-Terry：`P(y_w ≻ y_l) = σ(r_w − r_l)`。
KL 约束下的最优策略满足 `r(x,y) = β log(π(y|x)/π_ref(y|x)) + β log Z(x)`。
两回答相减，`Z(x)` 消掉：`r_w − r_l = β(Δ_w − Δ_l)`，`Δ = log π − log π_ref`。
代回 Bradley-Terry 得到 `L = −log σ(β(Δ_w − Δ_l))`。
检查：`π = π_ref` 时损失是 `log 2 ≈ 0.693`。本仓库第一步就是这个数。

## IPO 在参考策略处的值

`L = (Δ_w − Δ_l − 1/(2β))²`。`π = π_ref` 时 `Δ_w = Δ_l = 0`，损失是 `(1/(2β))²`。
`β=0.1` 时 `1/(2β)=5`，损失是 25。本仓库第一步是 25。

## RLOO 和组内均值差一个系数

`Â_i = r_i − mean_{j≠i} r_j = K/(K−1) · (r_i − mean_j r_j)`。

leave-one-out 均值不含 `r_i`，所以在同组其他样本给定时，baseline 不依赖第 i 条样本自己的动作。
除以组内标准差之后这个无偏性不再是讨论重点，低方差组会被放大，见题库 Q13。

## k3 估计 KL

要估计的是 `E_π[log(π/π_ref)]`。令 `r = π_ref/π`，则 `E_π[r] = Σ π · π_ref/π = 1`。
`k3 = r − 1 − log r`，期望等于 `E[log(π/π_ref)]`，无偏。
`log r ≤ r − 1`，所以 k3 ≥ 0。k1 无偏但可以为负。

## IQL 的 expectile

`L_2^ζ(u) = |ζ − 1{u<0}| u²`，其中 `u = Q(s,a) − V(s)`。
`ζ=0.5` 是普通均方误差。`ζ>0.5` 时，Q 高于 V 的一侧权重大，V 去追数据里较高的动作价值。
Q 的目标用 `r + γV(s')`，不在 `s'` 上取 max，也不采样下一个动作。

## 离散 CQL

惩罚 `α(logsumexp_a Q(s,a) − Q(s, a_data))`。
前一项把所有动作的 Q 往下压，后一项把数据动作加回来。α=0 时这一项消失，OOD 动作的 Q 可以高于数据动作。
本仓库 oracle 数据上 α=0 全部失败（−150），α=0.01 就能解。

## 无偏 pass@k

每题采 n 条，对了 c 条。`pass@k = 1 − C(n−c, k) / C(n, k)`，要求 `n ≥ k`。
这是「从 n 条里抽 k 条、至少一条正确」的概率，不是某一次抽 k 条的结果。
`c=0` 时为 0。`c=n` 时为 1。

## 0.5B 的静态显存

`N=5×10^8`。bf16 权重 1 GB，fp32 主权重 2 GB，Adam 两个矩 4 GB，bf16 梯度 1 GB，共 8 GB。
参考模型另加 1 GB。logits 是 `B·T·|V|·4` 字节，不在这 8 GB 里。
