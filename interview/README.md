# 面试准备

| 文件 | 什么时候打开 |
| --- | --- |
| [PORTFOLIO.md](PORTFOLIO.md) | 讲自己的工作。每条有 20 秒结论，以及这组数字**不能**推出的结论 |
| [FORMULAS.md](FORMULAS.md) | 对方说「写一下」。每条公式带四行推导和一个可口算的检查 |
| [QUESTION-BANK.md](QUESTION-BANK.md) | 课程讲得少的专题。每节末尾是一句常见错答 |

| [ENGINEERING.md](ENGINEERING.md) | 系统岗：显存乘法、bug 清单、评测口径 |

课程主干的一句话答案在 [COURSE-QA.md](COURSE-QA.md)，追问链在 [notes/](../notes/README.md)。
每份作业另有一份面试知识总结 PDF：`solutions/*/*/reports/interview_guide/main.pdf`。

准备方式：算法岗只练故事 4 和 5，系统岗只练故事 1 和 2。先用 90 秒讲完 20 秒结论和 STAR，
再不看稿写出对应的公式，最后用该节的错答反过来问自己。
