## 摘要

长时域任务需要时间抽象：把「做什么」与「怎么做」解耦，高层输出子目标/子任务，低层负责执行。
本讲围绕层次化的三个设计问题展开——子目标如何表示（语言/图像/状态）、各层如何监督
（演示切分/规划器/RL/HER）、何时切换（固定步数/分类器/学习终止）。重点案例：语言子目标的
层次模仿学习与高层 DAgger、技能发现（DIAYN），以及 VLM+VLA 的现代层次架构。

## 一页速览卡（面试前 5 分钟）

**必须记住的五件事**

1. Option `(I_ω, π_ω, β_ω)`：启动集、子策略、终止条件；半 MDP 上做高层决策。
2. 三个设计问题：子目标表示、各层监督、切换时机。
3. 层次 IL 流程：高层 `π_high(z|s,instruction)` + 低层 `π_low(a|s,z)`，分层条件 BC。
4. 高层用 DAgger：让高层自己运行、人工纠正子目标，解决错误传播。
5. 技能发现：最大化 `I(s;z)`（DIAYN），得到可复用、可组合的技能库。

**必须能默写的公式**

```text
Option 值: Q(s,ω) = E[ Σ_{t=0}^{τ−1} γ^t r_t + γ^τ max_{ω'} Q(s_τ, ω') ]
DIAYN:     max_z E[ log q(z|s) ] + H(z) − H(π) ⇒ 最大化 I(s;z) 并保持多样
层次收益: O(poly(H)) → m + O(poly(H/m))（理想分解）
```

**一句话区分**

- Options vs skills：人工/演示定义的时序抽象 vs 无监督发现的技能。
- 语言子目标 vs 图像子目标：语义泛化强 vs 空间精确但语义弱。
- 低层 DAgger vs 高层 DAgger：动作级纠正 vs 子目标级纠正（覆盖更长时段）。

## 核心概念

### 1. 长时域问题

「做一份 focaccia」这类任务：上千步、多阶段、奖励稀疏、单层策略难以信用分配。
层次化的基本思想：把长任务分解为可管理的子任务，用时间抽象降低有效时域。

### 2. Options 框架

Option 是「带终止条件的策略」：

```text
ω = (I_ω, π_ω, β_ω)
I_ω: 可启动状态集合
π_ω: 子策略（在 option 内部的动作分布）
β_ω: 终止概率 β_ω(s)（或到达目标即终止）
```

半 MDP（semi-MDP）中，高层在选择 option 时按「option 执行期间累计折扣回报」决策。
Option 可以是人工设计的子技能、从演示中切分的阶段，或自动发现。

### 3. 层次化的三个设计问题

1. **子目标怎么表示**：语言指令（“把袋子扶正”）、图像（目标帧）、状态（关节/物体位姿）、
   隐向量/技能编号；
2. **各层怎么监督**：上层（子目标）来自语言标注/规划器/演示切分；下层（动作）
   来自遥操作/关节控制；RL 则需要奖励或 HER；
3. **何时切换子目标**：固定执行 K 步、分类器判断完成、学习终止函数、或 VLM 判断。

### 4. 层次化模仿学习（语言子目标）

流程（HULC/LCBC 风格）：

```text
数据：演示轨迹 + 语言子任务标注（人工或自动切分）
高层策略：π_high(z_lang | s, instruction)     —— 预测下一段该做什么
低层策略：π_low(a | s, z_lang)                —— 执行子任务
训练：各层分别做条件 BC（或联合训练）
测试：高层给出子目标，低层执行若干步，再询问高层
```

高层策略用**DAgger** 修正：让它自己运行，由人工把错误子目标纠正为正确指令，
重新训练。为什么需要：高层的错误会传播到整个子任务，闭环纠正数据价值高。

### 5. 层次化 RL 与技能发现

- 高层 RL：动作 = 子目标/技能，奖励 = 环境回报 + 子目标达成奖励；
- 低层：goal-conditioned 策略（L12），用 HER 学「到达任意子目标」；
- **技能发现（无监督）**：DIAYN 最大化 `I(s; z)`（技能与访问状态的互信息），
  让不同 `z` 产生可区分的技能；DADS 用动力学可预测性；LSI 等在此基础上精细化。
- 技能库可被高层复用，形成可组合性。

### 6. 现代实践：VLM + VLA 层次

- SayCan：LLM 规划技能序列，用可行性（affordance）筛选；
- π0.5 / GR00T N1：高层（VLM/语言）生成子任务或子目标，低层 VLA 执行；
- 层次化也被用于长程操作与移动操作；关键是高层语义泛化 + 低层执行精细。

## 关键推导：层次化为什么降低样本复杂度

设单层任务有效时域 `H`，探索/信用分配的复杂度随 `H` 增长（如 `poly(H)`）。
把任务分解成 `m` 个阶段、每段长度 `H/m`，低层学可复用的技能，高层在 `m` 步上决策。
在理想条件下总复杂度由 `H` 型降为 `m + (H/m)` 型——这正是 options/半 MDP 的理论收益。
代价是子目标表示与切换设计引入的近似误差。

## 深入推导

### 推导 1：options 的价值分解

半 MDP 中，定义 option `ω=(I,π,β)`，其价值满足 Bellman 式：

```text
Q(s,ω) = E[ Σ_{t=0}^{τ−1} γ^t r_t + γ^τ max_{ω'} Q(s_τ, ω') | s, ω ]
```

其中 `τ ~ β` 是 option 的终止时间。高层在「option 作为动作」的 MDP 上决策，
低层执行 `π_ω`。当 `τ≡1` 且每个 `ω` 对应单步动作时，退化为普通 MDP——层次化是它的推广。

### 推导 2：DIAYN 的互信息下界

目标：`max I(s;z)=H(z)−H(z|s)`。用变分分布 `q_φ(z|s)` 近似 `p(z|s)`：

```text
I(s;z) ≥ E_{z~p(z), s~π_z}[ log q_φ(z|s) ] + H(z)
```

再减去策略熵 `H(π)`（鼓励动作多样），得到 DIAYN 目标：
`E[log q(z|s)] + H(z) − H(π)`。直观：状态要可区分技能（第一项）、技能先验要均匀（第二项）、
技能内部要尽量随机（第三项）。学完后 `q(z|s)` 可当判别器，`z` 就是可复用的技能编码。

### 推导 3：层次化的样本复杂度

设任务有效时域 `H`，平坦方法的学习复杂度约为 `O(poly(H))`。把任务分为 `m` 段、
每段 `H/m` 步：

- 低层学「到达任意短程目标」的策略，复杂度 `O(poly(H/m))`；
- 高层在 `m` 步上决策，复杂度 `O(poly(m))`；
- 合计 `O(poly(m) + poly(H/m))`，在 `m≈√H` 时取到远小于 `poly(H)` 的值。

这解释了选项/技能为何有效，也说明分解的近似误差与切换开销是层次化的隐式代价。

## 易错点与反例

- **高层/低层分布不匹配**：低层没见过高层给的子目标 → 用低层可达目标采样或联合微调；
- **子目标太抽象或太细**：抽象则低层学不会，细则高层序列过长；
- **终止条件学不好**：过早/过晚切换都会破坏长程表现；
- **高层数据缺乏纠正**：只模仿专家数据，看不到自己犯错的状态（与 BC 同样的问题）；
- **技能无区分度**：`I(s;z)` 未充分优化，技能库退化。

## 高频问题

- 问：层次化的三个设计问题？答：子目标表示、各层监督、切换时机。
- 问：options 是什么？答：带启动集、子策略与终止条件的时序抽象。
- 问：高层为什么需要 DAgger？答：子目标错误会传播，纠正数据把高层带到测试分布。
- 问：无监督技能发现的原理？答：最大化技能与状态/动力学之间的互信息。
- 问：层次化与多任务/目标条件的关系？答：子目标是一种任务条件，层次结构是任务条件的组合。

## 面试追问链（由浅入深）

1. 层次化一定会更好吗？→ 不一定：分解引入近似误差与切换开销；
   当任务天然可分阶段、且低层技能可复用时收益最大。
2. 子目标的粒度怎么选？→ 太细高层序列长、信用分配难；太粗低层学不会；
   可用互信息或可达性准则自动切分。
3. 为什么高层也要闭环（DAgger）？→ 高层错误会让低层执行完全错误的子目标，
   错误跨越整个子任务；纠正数据必须覆盖高层犯错的分布。
4. 终止函数可以学习吗？→ 可以（如 option-critic 的 termination gradient），
   但训练不稳定；实践常用固定步数或分类器。
5. 技能发现与 GCRL 的关系？→ 技能可视为「隐目标」；GCRL 用显式目标状态，
   DIAYN 用互信息发现隐技能，两者可结合（DADS 学动力学可预测技能）。
6. VLM 层次架构的瓶颈在哪？→ 高层的语义规划与低层的执行接口（子目标表示、
   频率、错误恢复）；以及真实数据稀缺。
