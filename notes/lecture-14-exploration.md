## 摘要

探索是 RL 样本效率的根源问题：利用当前最优动作 vs 收集能改进决策的信息。本讲（2025 版补充）
从遗憾最小化出发，梳理简单策略（ε-greedy/softmax/乐观初始化）、不确定性方法
（计数/UCB/Thompson 采样）与内在奖励（ICM/RND/熵/信息增益），并讨论噪声电视等陷阱。
实用探索通常是「熵/ε（局部）+ 内在奖励（全局）+ 后验采样（信息导向）+ 课程/演示（结构化）」
的组合。

## 一页速览卡（面试前 5 分钟）

**必须记住的五件事**

1. 目标：最小化遗憾 `Regret(T)=T·r*−Σr_t`；老虎机有对数遗憾算法。
2. 简单策略：ε-greedy、softmax 温度、乐观初始化；不利用不确定性。
3. 不确定性：计数/UCB 加成、集成方差、Thompson 采样（从后验采样假设再贪心）。
4. 内在奖励：ICM 前向预测误差、RND 随机网络蒸馏、熵、信息增益。
5. 陷阱：噪声电视、内在奖励压过外部奖励、真机探索的安全约束。

**必须能默写的公式**

```text
UCB:      a_t = argmax_a [ μ̂(a) + c √( log t / N(a) ) ]
MaxEnt:   J(π) = E[ Σ_t ( r_t + α H(π(·|s_t)) ) ]
RND:      L = E[ || f_θ(s) − f_target(s) ||² ],  r_int = ||·||²
```

**一句话区分**

- 计数 vs 预测误差：访问次数 vs 模型新颖度；后者可推广到连续状态但易被随机性欺骗。
- UCB vs Thompson：确定性乐观 vs 后验随机；后者通常更符合贝叶斯最优。
- 外挂探索 vs 内生探索：`ε`-greedy vs 熵正则/内在奖励。

## 核心概念

### 1. 为什么需要探索

最优策略需要全局信息，但智能体只能通过行动获得信息：

- **利用（exploitation）**：选择当前估计最优的动作；
- **探索（exploration）**：尝试可能更差但能提供信息的动作。

遗憾（regret）目标：与事后最优策略的累计差距 `Regret(T) = T·r* − Σ_t r_t`。
在多臂老虎机中，UCB/Thompson 可达到对数级遗憾；在 MDP 中问题更难。

### 2. 简单探索策略

| 方法 | 形式 | 特点 |
| --- | --- | --- |
| `ε`-greedy | 以 `ε` 概率随机 | 简单；不利用不确定性 |
| Softmax/Boltzmann | `a ~ softmax(Q/τ)` | 按价值差距分配概率 |
| 乐观初始化 | `Q ← Q_max` | 鼓励访问未尝试动作 |
| 计数/UCB | `a = argmax Q + c√(log t / N(a))` | 理论保证，离散/表格友好 |

深度 RL 中 `ε` 衰减、熵正则（SAC/PPO）是最常用的实用探索。

### 3. 内在奖励（intrinsic motivation）

当外部奖励稀疏时，构造「新奇度」奖励：

- **计数/伪计数**：状态访问次数（或密度模型导出的伪计数）；
- **ICM**：用前向模型预测误差 `||φ(s') − f(φ(s),a)||²` 作为好奇奖励，
  同时可训练逆模型提取与动作相关的特征；
- **RND（Random Network Distillation）**：固定随机网络输出为目标，
  训练预测网络；预测误差大 = 新颖状态；
- **信息增益/熵**：鼓励减少对任务参数的不确定性（与 L13 后验采样呼应）。

风险：**噪声电视（noisy TV）问题**——随机性强的区域永远有预测误差，导致智能体沉迷。
缓解：只对可控/与环境交互相关信息给奖励，或用集成/贝叶斯不确定性。

### 4. 基于不确定性的探索

- **贝叶斯/集成 Q**：不确定性高（方差大）的动作获得探索加成（如 UCB 风格
  `a = argmax Q + κσ`）；
- **Thompson sampling**：从 Q 的后验采样一个假设再贪心（posterior sampling）；
- **RND/ICM** 是它的近似实现。

### 5. 最大熵 RL

SAC 的目标 `E[Σ r + αH(π)]` 把探索写进目标函数：

```text
J(π) = E[ Σ_t ( r_t + α H(π(·|s_t)) ) ]
```

好处：不依赖外部探索启发式；温度 `α` 自动调节熵水平。PPO 中常用熵系数 `c_ent`。

### 6. 稀疏奖励的组合拳

实践上通常组合使用：

1. 演示/BC 预热（HW2 的 BC 预训练、RLPD）；
2. 课程学习与目标重标（HER，L12）；
3. 内在奖励（RND/ICM）；
4. 后验采样/集成不确定性（PEARL、SAC+ensemble）；
5. 随机化环境参数（domain randomization 也是被动的探索）。

## 关键推导：UCB 的直觉

对每个动作维护均值 `μ̂(a)` 与访问次数 `N(a)`，选择

```text
a_t = argmax_a [ μ̂(a) + c √( log t / N(a) ) ]
```

- 第一项利用，第二项探索；
- `N` 小则探索加成大；`t` 大则被迫逐步尝试所有动作；
- 在独立同分布老虎机下可达 `O(log T)` regret。MDP 中状态相关版本需要
  count 或不确定性的函数近似。

## 深入推导

### 推导 1：UCB 的置信半径从哪来

对单个动作，`N` 次采样均值 `μ̂` 与真实 `μ` 的偏差由 Hoeffding 不等式控制：

```text
P( |μ̂ − μ| ≥ u ) ≤ 2 exp(−2N u²)
```

令右侧为 `δ`，得 `u = √( log(2/δ) / (2N) )`。对所有动作与所有时刻取并集界
（`δ ~ 1/t²`），得到熟悉的 `√( log t / N )` 形式。这就是 UCB 探索加成的来源。

### 推导 2：Thompson sampling 的后验更新

以 Beta-Bernoulli 老虎机为例，先验 `Beta(α,β)`，观测成功/失败后

```text
α ← α + 1（成功）,   β ← β + 1（失败）
每步从 Beta(α,β) 采样一个 θ̃，选择 argmax_a θ̃_a
```

后验方差随观测下降；采样天然实现「不确定性大的动作更可能被选中」，
在贝叶斯设定下达到与 UCB 同阶的遗憾。

### 推导 3：RND 的最优预测器

RND 固定随机网络 `f*`，训练 `f_θ` 回归 `f*(s)`，内在奖励 `r_i=||f_θ(s)−f*(s)||²`。
对固定分布内的状态，最优预测器使误差趋于该状态的可预测性残差；新颖状态误差大。
注意：若状态含不可约随机性（噪声电视），误差下界不为零，奖励会持续被吸引。

### 推导 4：熵正则的策略梯度

对 `J=E[Σr]+α H(π)`，策略梯度多出一项：

```text
∇_θ H(π(·|s)) = −∇_θ Σ_a π(a|s) log π(a|s)
             = −E_{a~π}[ (log π(a|s) + 1) ∇log π(a|s) ]
```

该项把概率质量从「过于确定」的动作上推开，等价于给低概率动作正权重。
`α` 与外部奖励的比值决定探索强度，可用目标熵自动调节（SAC 的温度）。

## 易错点与反例

- **`ε` 一直很大**：策略永远无法收敛到最优；
- **内在奖励压过外部奖励**：需要退火或归一化；
- **噪声电视问题**：预测误差奖励会被随机区域吸引；
- **只探索不加利用**：replay 数据分布过散，critic 学不好；
- **探索与安全**：真机探索需要约束（safe RL、shield）。

## 高频问题

- 问：探索-利用的数学框架？答：遗憾最小化；老虎机有对数遗憾算法。
- 问：RND 与 ICM 的差别？答：RND 用固定随机网络的预测误差；ICM 用前向动力学误差 + 逆模型。
- 问：SAC 的熵项与 `ε`-greedy 的关系？答：前者是目标函数内生的探索，后者是外挂噪声。
- 问：posterior sampling 为什么是好的探索？答：按当前信念随机选假设并最优行动，天然平衡信息与回报。
- 问：稀疏奖励的最佳实践？答：演示预热 + 课程/重标 + 内在奖励 + 不确定性，多管齐下。

## 面试追问链（由浅入深）

1. ε-greedy 的 ε 为什么要衰减？→ 初期需要覆盖所有动作；后期继续随机会损失
   `ε·(r*−r_avg)` 的回报。
2. UCB 的第二项为什么是 `√(log t / N)`？→ 来自 Hoeffding 不等式与并集界的置信半径；
   访问越少、总步越多，加成越大。
3. 内在奖励为什么会「沉迷噪声」？→ 预测误差在随机区域永远存在；
   需要对可控性/信息增益建模或用集成不确定性。
4. 探索和安全的矛盾怎么处理？→ 约束 MDP、shielding、人在环干预、只在仿真里激进探索。
5. 为什么稀疏奖励推荐组合拳？→ 单一方法覆盖不全：演示给起点、课程给梯度、
   内在奖励给新奇度、后验采样给信息导向。
6. 后验采样为什么比 ε-greedy 好？→ 它按后验概率分配探索，且「一以贯之」地执行
   假设最优策略，避免无信息的随机动作。
