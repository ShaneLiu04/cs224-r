## 核心概念

### 1. 学一个模拟器

收集数据 `D = {(s_t, a_t, s_{t+1})}`，用最大似然学动力学：

```text
L_model(θ) = −E_{(s,a,s')~D}[ log p_θ(s' | s, a) ]
```

得到模型后有两种用法：

1. **Dyna 风格**：用模型生成的 `(s,a,r,s')` 加入 replay，和真实数据一起更新值/策略；
2. **规划**：用模型在测试时做轨迹优化/搜索，直接选动作。

模型可以是确定性的（MSE）、高斯、集成（ensemble）、latent（Dreamer）、甚至视频模型。

### 2. 模型误差与分布偏移

模型在训练分布内可能很准，但策略会主动寻找「模型错误却预测高回报」的区域，
使 rollout 越来越偏离真实分布并放大误差。这与离线 RL 的 OOD 问题同构：
**数据支撑之外不可信**。

缓解手段：

- **集成 + 不确定性惩罚**（PETS、MOPO）：惩罚高方差区域的奖励；
- **短 rollout**：只展开几步就从真实状态重新出发（MBPO）；
- **保守/信任域**：限制策略偏离行为策略；
- **模型正则**：早停、权重衰减、数据增广。

### 3. MBPO 算法

```text
repeat:
  1. 用当前策略 π 在真实环境收集数据 → D_env
  2. 在 D_env 上训练动力学模型（通常 ensemble）
  3. 从 D_env 中的真实状态出发，用模型展开短 rollout（长度 k，如 1~5）
  4. 把模型数据加入 D_model，更新 actor-critic（SAC）
```

为什么短 rollout：模型误差随步数复合增长（每步误差近似指数放大），`k` 小则偏差低；
但 `k` 太小又退化成一次函数近似。MBPO 的分析给出了在模型误差与策略改进之间的长度选择。

### 4. 规划（Planning）

测试时用模型优化动作序列：

| 方法 | 思路 | 优缺点 |
| --- | --- | --- |
| 随机打靶 | 采样 N 条动作序列，取回报最高 | 简单；高维动作低效 |
| CEM | 迭代拟合精英样本分布（交叉熵方法） | 稳定通用；计算量大 |
| MPPI | 采样 + 重要性加权更新 | 控制领域常用 |
| 树搜索 | 离散动作上做 MCTS/AlphaZero | 强但需要值函数与模型 |

MuJoCo MPC（MJPC）是交互式预测控制的代表（2023/2025 的 HW2 曾用它做奖励设计）。
AlphaZero/MuZero 展示了「学模型 + 搜索 + 学值」的组合。

### 5. 何时用 model-based

优点：

- 样本效率高（用模型生成数据或减少交互）；
- 可做规划、支持反事实推理；
- 天然支持多任务/目标切换（换奖励重新规划）。

缺点：

- 模型误差导致 exploit 与不稳定；
- 高维观测（像素）建模难、计算贵；
- 与 model-free 的调参复杂度叠加。

经验：低维状态、接触丰富的控制、样本极贵（真机/化工/芯片）时 MBRL 优势最大；
语言/大视觉模型中「用学到的世界模型做 RL」仍是开放问题。

### 6. 其他模型形态

- **Latent dynamics**：在表示空间建模（Dreamer 系）；
- **奖励模型/价值等价模型**：建模 return 而非动力学（如 AlignRL、Decision Transformer 的视角）；
- **视频生成模型**：作为带像素的模拟器（Genie、世界模型路线）。

## 关键推导：模型误差复合

设单步模型误差为 `ε`，每步状态分布偏移近似累加并放大。经过 `k` 步展开，
回报估计误差大致随 `k` 增长超线性；策略在误差大的区域优化会「把误差当奖励」。
因此在 `k` 与「策略改进幅度」之间存在权衡，MBPO 通过经验与理论给出短 `k` 的选择。

## 易错点与反例

- **用模型数据训练太久**：策略跑进模型盲区，回报崩塌；
- **模型集成不 detach**：训练时把其他模型的梯度带进来；
- **归一化不一致**：模型训练与 rollout 的观测/动作归一化必须一致；
- **规划只看预测回报**：忽略不确定性会选到「模型幻想」的高分轨迹；
- **把 MBRL 当作必然更好**：模型本身的学习成本可能超过省下的交互。

## 高频问题

- 问：MBRL 的核心 trade-off？答：样本效率 vs 模型偏差；误差随 rollout 长度放大。
- 问：MBPO 为什么只展开几步？答：控制复合误差，同时提供比单步更有效的策略改进。
- 问：model-based 与 model-free 能否组合？答：可以，模型数据 + 真实数据混合更新很常见。
- 问：规划与学习的区别？答：规划在线优化动作序列，学习把结果蒸馏进策略/值函数。
- 问：MuZero 的主线思想？答：只学「预测奖励、价值、动作选择」的隐模型，用于搜索。

## 本讲小结

MBRL 用模型换样本效率，核心难点是模型误差的利用与抑制。短 rollout、集成、不确定惩罚、
保守约束是四大工具。下一讲处理另一个维度的泛化：多任务与目标条件策略。
