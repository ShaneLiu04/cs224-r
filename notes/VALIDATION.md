# 笔记校验

## 校验内容

[`check_notes.py`](check_notes.py) 对 18 篇笔记执行以下强校验：

| 检查 | 规则 |
| --- | --- |
| 文件完整 | 18 篇 2026/2025 讲次映射齐全 |
| 元信息 | 每篇含「课程版本 / 日期 / 官方材料 / 状态」 |
| 结构 | 每篇含 15 个必需章节（摘要 → 延伸阅读） |
| 深度推导 | L02–L17 必须含 `## 深入推导`（L01 概览、L18 方法论除外） |
| 公式 | 每篇 ≥2 个 fenced 公式/代码块，非空 |
| 追问与自测 | 每篇含面试追问链与自测题（带要点） |
| 关联 | 每篇 `## 关联笔记` ≥2 条有效内链 |
| 链接 | 所有相对链接（slides/其他笔记/仓库文件）在磁盘上存在 |
| 索引 | `notes/README.md` 索引全部 18 篇 |
| 术语 | `GLOSSARY.md` 覆盖 16 个必查关键术语 |
| 占位符 | 不允许 TODO/TBD/待补/待写 |

## 运行

```bash
python notes/check_notes.py
python notes/check_notes.py --verbose
```

## 内容口径

- 每篇引用对应官方 slides 与视频（若有），公式符号与官方讲义一致；
- 作业细节以 `assignments/` 中对应版本 handout 为准；
- 2026 版无第 14 讲 exploration，L14 基于 Spring 2025 版本整理；
- 「深入推导」以自包含为目标：关键结论都给出步骤、假设与失效边界。

## 状态

- 18 篇均为「初稿」；每学完一讲可升级为「已复习 / 已验证」；
- 升级「已验证」的标准：默写公式 + 跑通对应实验/作业 + 能回答追问链全部问题。
