## 摘要

VLA（Vision-Language-Action）模型是机器人基础模型的主流形态，但纯模仿学习常平台在约 80%
成功率。本讲讨论 VLA 上做 RL 的难点（模型大、真机采样贵、奖励稀疏、diffusion/flow 策略
似然难算），并给出三条可行路线：离线迭代（监督学 V + advantage-conditioned 行为克隆）、
全参在线 PPO（昂贵）、轻量在线（冻结 VLA，学残差/噪声编辑器）。核心范式是
「大模型 + 小 RL 策略 + 迭代数据」。

## 一页速览卡（面试前 5 分钟）

**必须记住的五件事**

1. IL 平台期：演示分布外的长尾失败；RL 后训练用于突破。
2. 四大难点：模型大、采样贵、奖励稀疏、策略似然难算（diffusion/flow）。
3. 离线配方：MC 学 `V(s)` → 优势条件监督 `π(a|s, A>0)` → 迭代收集数据。
4. 在线轻量：残差策略 `a=a_VLA+a_res`、diffusion steering（学噪声编辑）。
5. 共同原则：不轻易全参更新大模型；把 RL 放在小网络/小策略上。

**必须能默写的公式**

```text
优势条件 BC: L = −E_{(s,a)~D, A(s,a)>0}[ log π_θ(a | s, success) ]
残差策略:     a = a_VLA(s) + a_res,θ(s),  只训练 a_res
MC 值函数:    V(s) ≈ E[ 1[episode 成功] | s ]
```

**一句话区分**

- 过滤 BC vs 优势条件：硬阈值丢数据 vs 软条件保留多样性。
- 全参 PPO vs 残差/steering：上限高但成本高 vs 便宜、安全、易迭代。
- MC 值 vs TD 值：高方差无偏 vs 可跨步传播但需要更多工程。

## 核心概念

### 1. VLA 是什么

VLA 把视觉 + 语言指令映射为动作序列，通常由预训练 VLM + 动作头（自回归 token、
diffusion/flow head）构成。训练以模仿学习为主（机器人演示 + 人类视频），
代表：OpenVLA、π0/π0.5、GR00T N1/N2、RT-2。

### 2. 为什么 VLA 需要 RL

- IL 在多样化数据上常**平台在 ~80% 成功率**：长尾失败、分布漂移、任务约束难以演示；
- RL 能用奖励继续提升，尤其擅长修正「差一点成功」的边界行为；
- 类比 LLM：预训练/SFT 打底，RL 后训练提升任务表现。

### 3. 为什么 VLA 上做 RL 难

1. **模型大**：全参数 RL 微调显存/算力昂贵；
2. **采样贵**：真实机器人 rollout 慢且不可并行；
3. **奖励稀疏**：成功/失败信号，偏置在长时域；
4. **安全**：探索可能损坏硬件/环境；
5. **分布**：diffusion/flow 策略的似然难算，PPO 类方法不直接适用。

### 4. 离线 RL 微调配方（推荐起点）

以 π0.5 之后的实践为例：

```text
1. 用成功/失败数据训练值函数 V(s)（Monte Carlo 回报：成功 1、失败 0）
2. 计算优势 A(s,a) ≈ V(s) − 或 return − V
3. 用 advantage-conditioned 监督学习更新 VLA：
   在 prompt/条件里加入「好/坏」token（advantage conditioning），只对好样本模仿
4. 迭代：新策略收集数据 → 更新 V → 再训练
```

优点：不需要对 VLA 做 policy gradient；复用监督训练管线；
值函数是监督式的（MC），稳定。风险：MC 值高方差、离线数据覆盖有限。

### 5. 在线 RL 的轻量化路线

- **PPO 直接微调**：OpenVLA / π0.5 上的实验显示可行但昂贵、调参敏感；
- **Diffusion steering**：冻结 VLA，学一个小策略输出噪声/编辑向量，使采样动作更好；
- **残差策略（residual policy）**：`a = a_VLA + a_res(s)`，只训练小网络；
- **动作编辑器**：学高斯策略对 VLA 动作做局部修正（scale/shift/selection）。

共同主题：**不要动大模型**，把 RL 放在小策略/小价值网络上，迭代式收集数据。

### 6. 迭代式离线 RL 循环

```text
π_0 (SFT VLA)
  → rollout 收集数据（含失败）
  → 训练 V(s)（MC）
  → advantage 加权/条件微调 π
  → 新数据 ... 重复
```

这是「iterated offline RL」范式：每轮都用当前策略数据，避免纯离线分布问题，
同时控制真机风险（少量多次、成功经验优先）。

### 7. 训练阶段观察

- 初期：MC 值函数帮助策略快速爬升；
- 后期：需要更好的信用分配（TD、过程奖励）以突破平台；
- 不同任务的最优点不同，配方需要按任务调整。

## 关键推导：为什么 advantage conditioning 能替代 policy gradient

离线数据下策略梯度需要 `∇log π_θ(a|s)`（对 diffusion/flow 不方便）与行为分布修正。
若把优势当作**条件**：`π_θ(a | s, A>0)`，则只需对「有正优势的样本」做条件 BC：

```text
L = −E_{(s,a)~D, A(s,a)>0}[ log π_θ(a | s, success) ]  （示意）
```

推理时用 `success` 条件生成动作。它与过滤 BC 的区别在于使用连续/分级条件，
保留多样性并可在推理时控制行为。

## 深入推导

### 推导 1：MC 值函数的方差与 baseline

`V(s)=P(成功|s)` 的 MC 估计是 0/1 标签的均值，单条轨迹方差 `V(1−V) ≤ 0.25`。
用 `n` 条轨迹平均，方差降到 `V(1−V)/n`。相比 TD，MC 无偏但需要完整 episode；
在稀疏长任务中可先用 MC 获得稳定信号，再逐步引入 TD（需要工程投入）。
基线技巧：用 `A(s,a)=G−V(s)` 只保留相对优势，进一步降低方差。

### 推导 2：advantage conditioning 是 filtered BC 的软版本

过滤 BC 只保留 `A>0` 的样本：

```text
L_filter = −E_{(s,a): A>0}[ log π_θ(a|s) ]
```

它丢弃大量边界数据，且推理时无「好坏」控制。优势条件把标签作为条件：

```text
L_cond = −E_{(s,a)}[ log π_θ(a | s, c(A)) ]
```

`c` 可以是离散 token（good/bad）或分桶分位数。推理时给 `good` 条件即得改进策略；
训练数据全部保留，因此能学到「如何变好」而不仅是「好的样子」。

### 推导 3：残差策略的最优形式与投影

设基座动作 `a_0=π_VLA(s)`，残差 `a=a_0+δ_θ(s)`。对 `Q` 的最优残差近似为
在基座动作附近的 Q 梯度步：

```text
δ* ≈ η ∇_a Q(s,a) |_{a=a_0}
```

小网络学的是「局部修正方向」。限制 `||δ||≤ε`（动作裁剪/正则）等价于信任域约束，
保证不破坏基座能力。若基座动作多模态（flow/diffusion），梯度在噪声维度上传播更复杂，
常用 steering（学习噪声编辑）代替动作残差。

### 推导 4：迭代式离线 RL 的分布扩张

每轮：`π_k` 采样 → 数据集 `D_{k+1}=D_k ∪ D(π_k)` → 训练 `π_{k+1}`。
若探索有界，`D_k` 的支撑集合单调扩张，逐步覆盖测试分布；这也是「离线起步、
在线收敛」的共同机制（RLPD/Cal-QL 同理）。风险是失败数据无正信号，
需要成功优先/优势重加权来维持梯度质量。

## 易错点与反例

- **直接全参数 PPO**：显存/时间不可行，先用小策略/冻结主干；
- **MC 值方差**：稀疏奖励下 `V` 估计噪声大，需大量数据与平滑；
- **只用成功数据**：会忽略「接近失败」的宝贵信号；
- **忽略安全**：探索必须加物理约束/人工干预；
- **评测只看训练任务**：VLA 的价值在于泛化，需 held-out 指令/场景。

## 高频问题

- 问：VLA 为什么卡在 80%？答：IL 拟合演示分布，长尾/边界情况缺数据。
- 问：VLA RL 最难的成本项？答：真机采样与奖励，其次是模型大小。
- 问：离线 RL 微调 VLA 的关键？答：监督式 V 学习 + 优势条件的行为克隆。
- 问：在线 RL 的轻量方案？答：冻结 VLA，学残差/噪声编辑器/价值函数。
- 问：与经典 RL 的关系？答：同一套值/优势概念，只是函数近似换成了大模型。

## 面试追问链（由浅入深）

1. 为什么 VLA 需要 RL 而不是更多演示？→ 演示无法覆盖所有恢复行为与长尾；
   RL 用奖励信号在部署分布上直接优化。
2. diffusion/flow 策略为什么不能直接用 PPO？→ 动作是迭代生成的，
   `log π(a|s)` 难以精确计算；替代方案是重参数化、条件 BC 或编辑噪声。
3. 离线迭代为什么有效而不违反离线 RL 的假设？→ 每轮用当前策略收集新数据，
   分布随策略更新，逐步扩张覆盖；本质是「迭代式离线 RL」。
4. 残差策略会不会破坏 VLA 的泛化？→ 有风险；需限制残差幅度、正则、
   或用安全过滤器；好处是主干能力保留。
5. 如何降低真机采样成本？→ 仿真预训练 + 真机少量微调、并行环境、
   人在环干预、成功经验优先采样。
6. VLA RL 的评估应该怎么做？→ held-out 指令/场景、多任务、失败恢复；
   报告成功率与干预率，而不是只看训练奖励。
