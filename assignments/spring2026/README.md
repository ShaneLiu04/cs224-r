# Spring 2026 作业

当前版本。3 次作业 + 期中考试 + 期末项目（默认或自定义）。

| 作业 | 权重 | 截止 | 主题 | 计算 |
| --- | --- | --- | --- | --- |
| [HW1 Imitation Learning](homework1-imitation/README.md) | 10% | 4/10 | Flappy Bird：BC、flow matching、DAgger | CPU 可跑 |
| [HW2 Online RL](homework2-online-rl/README.md) | 15% | 4/24 | gridworld Q-learning、PPO、off-policy AC | Modal |
| [HW3 Offline RL](homework3-offline-rl/README.md) | 15% | 5/8 | AWAC、IQL、stitching | Modal |
| [Default Project](default-project/README.md) | 35% | 6/8 报告 | Countdown：SFT、IPO、RLOO | GPU/Modal |

- 期中考试：5/15（考试范围至 5/8）。
- 项目：默认项目（Countdown RL）或自定义研究项目；poster + 报告。

## 提交格式

- HW1：PDF 报告 + 代码 zip（含 4 个结果 txt）；
- HW2：PDF 报告 + 3 个代码文件 + W&B 导出的 CSV；
- HW3：PDF 报告 + `csv_data/`（每个实验 3 seeds 各一个 CSV）+ `cs224r/` 代码；
- 项目：按 `CS224R_Default_Project_Guidelines.pdf` / `CS224R_Custom_Project_Guidelines.pdf`。
