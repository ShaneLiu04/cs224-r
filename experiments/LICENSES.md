# 许可与镜像政策

## 本目录内容

- 所有条目均为原创摘要、短引用与链接；
- 不复制论文正文、讲义页面或第三方代码；
- 每条资料在 `SOURCES.yaml` 中记录 `license` 与 `mirror` 字段。

## 官方材料

课程 slides、作业 handout、starter code、项目指南版权归 Stanford 与课程团队所有，
本仓库作为个人学习镜像导入，保留原始文件与来源说明，不用于商业分发。
若权利人要求移除，请通过仓库 issue 联系。

## 社区材料

| license 字段 | 处理 |
| --- | --- |
| `MIT` / `Apache-2.0` / `BSD-3-Clause` | 可转载并注明来源 |
| `ARXIV` | 链接到 arXiv，不镜像 PDF |
| `YOUTUBE` | 只链接播放列表 |
| `SEE_SOURCE` | 只链接，不复制 |
| `UNKNOWN` | 只链接，不复制，并标注可信度 |

## Spoiler 政策

解答类仓库在 `SOURCES.yaml` 中标记为 `confidence: spoiler`，在文本中标注 🔴。
修读课程期间请勿打开；honor code 明确禁止参考与公开发布解答。
