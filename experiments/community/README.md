# 社区资料使用规则

本目录只链接第三方资料，不复制内容。所有条目都标注了可信度与 spoiler 级别。

## Spoiler 分级

| 级别 | 含义 | 建议 |
| --- | --- | --- |
| 🟢 安全 | 讲义笔记、教程、论文导读 | 随时可看 |
| 🟡 提醒 | 包含部分实现细节 | 自己实现完再看 |
| 🔴 剧透 | 作业解答/代码 | **修课时不要打开**；honor code 明确禁止 |

## 使用原则

1. 先官方（handout、slides、starter code），后社区；
2. 先自己写，再对照；引用任何思路时在 writeup 注明；
3. 不把社区代码复制进提交；
4. 链接失效时用 Wayback Machine 或 GitHub 存档；
5. 发现高质量资料时，登记到 `SOURCES.yaml` 后加入本目录。

## 推荐顺序

1. 🟢 官方 TA 笔记（Jubayer Ibn Hamid）——与课程口径最接近的补充阅读；
2. 🟢 `ai-course-notes`（中文笔记，覆盖面广）；
3. 🟢 `az9713` 的 transcript-grounded notes / tutorials（英文，系统性强）；
4. 🟡 各作业的社区实现（先完成自己的版本）；
5. 🔴 完整解答仓库（修课期间禁止）。
